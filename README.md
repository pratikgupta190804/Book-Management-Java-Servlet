# 📚 Book Management Application

This is a simple **Book Management Web Application** built using **J2EE (Java Servlets and JSP)**. It was created as a learning project to understand core concepts of Java EE such as Servlets, JDBC, and MVC pattern.

> ⚠️ This project does **not include** authentication or authorization features. It is focused only on CRUD (Create, Read, Update, Delete) operations with books.

---

## ✨ Features

- Add a new book with the following details:
  - Book Name
  - Book Edition
  - Book Price
- View the list of all books
- Edit book details
- Delete books from the list

---

## 💡 Technologies Used

- Java (Servlets, JSP)
- HTML & CSS
- JDBC for database connectivity
- MySQL (as the database)
- Apache Tomcat (for local deployment)
